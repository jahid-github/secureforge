
# SecureForge

Industrial OT/ICS Cyber Defense Platform

## Objective

SecureForge is a simulated industrial cybersecurity environment designed
to demonstrate secure IT/OT architecture, network segmentation,
industrial protocol monitoring, detection engineering, threat modelling,
incident response, and SOC integration.

## Core Technologies

- OPNsense
- OpenPLC
- Node-RED
- Modbus TCP
- MQTT
- OPC UA
- Suricata
- Zeek
- Wazuh
- Microsoft Sentinel
- Microsoft Entra ID
- Azure

## Security Frameworks

- IEC 62443
- NIST SP 800-82
- MITRE ATT&CK for ICS
